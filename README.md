Student Behavior Data Analysis

This project focuses on exploratory data analysis and visualization using a student behavior dataset.

## Objective
To analyze student behavior patterns and visualize relationships between variables using Python libraries.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Student Attitude and Behavior Dataset from Kaggle.

## Visualizations Created
- Gender Distribution
- Department vs Marks
- Study Time vs Marks
- Status vs Gender Comparison
- Correlation Heatmap

## Key Learnings
- Exploratory Data Analysis (EDA)
- Data Visualization Techniques
- Relationship Analysis Between Variables
- Data Cleaning and Preprocessing
- Analytical Thinking Using Visual Insights
